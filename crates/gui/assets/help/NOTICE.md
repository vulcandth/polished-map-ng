`master-help.html.inc` retains the complete pinned C++ literal source, including
its CRLF bytes protected from Git newline conversion by `.gitattributes`. The two
JSON files are generated adaptations by Polished Map NG contributors, © 2026:
version/path constants are expanded for Windows/Unix, HTML whitespace/entities
are decoded, and paragraphs, list items, styles and links become display blocks.
No source paragraph or external link is intentionally removed. No images,
external page contents or font files are included in this asset directory.

Run `python3 tools/help_assets.py` to verify the original SHA-256 and both
generated documents. `--write` rebuilds them without network access. The Rust
viewer adds a separate notice that this is upstream reference documentation
while NG parity is in progress; original product names and copyright remain.
